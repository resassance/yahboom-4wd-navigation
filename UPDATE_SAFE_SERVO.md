# Обновление на занятии: диапазон датчика 45–135°

Историческая инструкция для предыдущей версии. Текущий алгоритм и архив описаны в `UPDATE_STAGED_BYPASS.md`; безопасные углы и непрерывный ход сохранены.
1. Остановить программу на роботе через Ctrl+C.
2. Распаковать новый архив `yahboom-4wd-navigation-2026-10-13-safe-servo.zip`. Через SFTP скопировать `robot_navigation.py` и `navigation.py` в текущую папку робота `~/yahboom-4wd-navigation/13.10.26/`, заменив оба файла вместе.
3. В уже используемый `robot_config.json` добавить поля `"servo_min_deg": 45` и `"servo_max_deg": 135`. Остальные замеры сохранить. Если этих полей нет, новые классы используют те же границы по умолчанию. В архиве есть полный конфиг с вашими размерами и смещением 11 см.
4. Сначала запустить неподвижный обзор:

```bash
sudo python3 robot_navigation.py --config robot_config.json --mode scan --max-seconds 20
```

Проверить, что головка доходит только до выбранных границ без упора. При упоре внутри этого диапазона остановить запуск и уменьшить соответствующую границу. Программа не имеет обратной связи по усилию и не может самостоятельно обнаружить заедание.

5. Повторить закрытую постановку:

```bash
sudo python3 robot_navigation.py --config robot_config.json --mode plan --max-seconds 20
```

Ожидаемый результат закрытой постановки — `action: stop`. В журнале обзора не должно быть команд 0°, 158° или 180°. Новые углы рассчитываются внутри диапазона 45–135°.

6. Для свободной постановки сначала проверить `plan`. При разрешённом манёвре угол корпуса может быть около 18°, а не прежние 45°: иначе с узким обзором невозможно проверить весь проход при возврате. Физический угол пока оценивается по времени. Проверку `auto` проводить после неподвижного обзора на свободной площадке, сохранив полный журнал и видео.

`--use-ir` пока выключен. Коммит и отправка на GitHub не выполнялись. Старая версия архива без суффикса `safe-servo` содержит команды к крайним положениям и не включает это исправление.
