# Yahboom 4WD Navigation

Навигация четырёхколёсного робота Yahboom на Raspberry Pi: обнаружение препятствий ультразвуковым датчиком, поэтапный объезд с возвратом к исходному направлению и распознавание красного и синего через камеру.

## Возможности

- Непрерывное движение вперёд с контролем расстояния. При препятствии на расстоянии `safe_distance_cm` или ближе робот останавливается и осматривается.
- Обзор в девяти направлениях. Датчик поворачивается в пределах **45–135°**, центральное положение — 90°.
- Объезд с учётом габаритов корпуса: повороты по 45°, боковой проезд, поиск прохода к исходному направлению. При перекрытых путях или достижении лимита робот останавливается.
- Отдельный режим распознавания **красного и синего** без движения колёс и сервопривода.
- Видеопоток Flask для браузера. Один захват камеры используется для распознавания и всех зрителей.
- Журналы расстояний, команд моторам, углов датчика, решений навигации, результатов распознавания и ошибок.

В последнем обновлении добавлены распознавание цвета и его настройки, обработка ошибок камеры и ожидание первого кадра. Убран повторный обзор той же позиции при заблокированном боковом пути на предельном угле корпуса.

## Требования

- Raspberry Pi с Linux и Python 3.7 или новее.
- `RPi.GPIO` для приводов и датчиков.
- OpenCV (`cv2`), NumPy и Flask для камеры.
- Камера с индексом `0` и доступ к роботу по SSH.

Для режима `color` доступ к GPIO не нужен. Камера включается автоматически в `color` или флагом `--video` в остальных совместимых режимах. Используйте настроенное окружение робота; если для GPIO или камеры нужны права администратора, запускайте команды с `sudo python3`.

## Установка

```bash
git clone https://github.com/resassance/yahboom-4wd-navigation.git
cd yahboom-4wd-navigation
cp robot_config.json robot_config.local.json
```

Для обновления существующей копии:

```bash
git pull --ff-only
```

Перед заменой файлов сохраните свою рабочую версию. При ручном переносе копируйте вместе `robot_navigation.py`, `navigation.py`, `color_detection.py` и `color_config.json`. Локальные параметры робота храните в `robot_config.local.json`.

## Режимы запуска

| Режим | Назначение |
| --- | --- |
| `distance` | Измерение расстояния перед роботом |
| `scan` | Обзор без движения колёс; режим по умолчанию |
| `plan` | Обзор и вывод решения навигации без движения колёс |
| `ir` | Чтение сырых уровней выбранных ИК-входов без инициализации приводов и сервопривода |
| `turn` | Поворот корпуса на заданный угол по времени |
| `drive` | Прямой проезд заданной длительности |
| `auto` | Движение с обнаружением препятствия и объездом |
| `color` | Распознавание цвета и видеопоток без инициализации GPIO |

Расстояние, обзор и решение навигации:

```bash
python3 robot_navigation.py --mode distance --cycles 10
python3 robot_navigation.py --mode scan
python3 robot_navigation.py --config robot_config.local.json --mode plan --max-seconds 20
```

Короткие команды движения:

```bash
sudo python3 robot_navigation.py --mode turn --turn-deg 45
sudo python3 robot_navigation.py --mode turn --turn-deg -45
sudo python3 robot_navigation.py --mode drive --drive-seconds 0.5
```

Положительный угол означает поворот корпуса вправо, отрицательный — влево. В `turn` и `drive` нет автоматического разрешения движения по дальномеру; эти режимы предназначены для ручной калибровки на свободной площадке.

Автономное движение:

```bash
sudo python3 robot_navigation.py --config robot_config.local.json --mode auto --max-seconds 120
```

`--max-seconds` задаёт предельную длительность после инициализации: по умолчанию 30 секунд, максимум 600. Остановка — `Ctrl+C`. Завершение программы отключает PWM приводов.

## Распознавание цвета

```bash
python3 robot_navigation.py --mode color --max-seconds 120
```

Откройте `http://<IP-адрес-робота>:8080/` в браузере ноутбука в той же сети. В кадре отображаются область распознавания, рамка цветного объекта и результат:

- `RED` — красный;
- `BLUE` — синий;
- `UNKNOWN` — нет однозначного результата.

Цвет выделяется по HSV в центральной области кадра. Анализ выполняется до 5 раз в секунду на изображении шириной до 320 пикселей. Для подтверждения нужны три последовательных обработанных кадра одного цвета. При исчезновении цвета или появлении обоих цветов результат сбрасывается в `UNKNOWN`. Мелкие разрозненные пятна не суммируются в один объект.

Параметры находятся в `color_config.json`:

| Параметр | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `fps` | `5` | Максимальная частота анализа |
| `width` | `320` | Максимальная ширина изображения для анализа |
| `roi` | `[0.15, 0.15, 0.85, 0.75]` | Область `[x0, y0, x1, y1]` в долях ширины и высоты кадра |
| `min_area_ratio` | `0.04` | Минимальная доля площади одного связного цветного пятна внутри области |
| `min_saturation` / `min_value` | `100` / `60` | Нижние границы насыщенности и яркости |
| `confirm_frames` | `3` | Число последовательных кадров для подтверждения |
| `red_hue_ranges` | `[[0, 10], [170, 179]]` | Два диапазона красного на шкале оттенка OpenCV 0–179 |
| `blue_hue_range` | `[95, 130]` | Диапазон синего |

Нижняя четверть кадра исключена из области распознавания, чтобы уменьшить влияние пола и подсветки робота. Цветная поверхность должна находиться внутри рамки области. Пороги зависят от освещения и изображения камеры.

Для отдельного файла настроек:

```bash
python3 robot_navigation.py --mode color --color-config color_config.json --max-seconds 120
```

Распознавание пока служит для наблюдения. Выбор манёвра по цвету и продавливание синих препятствий ещё не подключены к навигации.

## Камера

В остальных режимах видеопоток включается флагом `--video`, например:

```bash
sudo python3 robot_navigation.py --config robot_config.local.json --mode auto --video --max-seconds 120
```

Адрес — `http://<IP-адрес-робота>:8080/`. Порт можно изменить через `--port`. Браузер показывает изображение; управление движением выполняется через программу.

Кадры кодируются в памяти. **Автоматического сохранения фотографий и видео нет.** Не запускайте одновременно другую программу, использующую ту же камеру.

Если камера не открылась, запуск прерывается. При отказе во время работы видеопоток завершается, а программа возвращает ненулевой код завершения. В `color` отказ завершает режим сразу после обнаружения; при дополнительном `--video` навигация продолжает работать до своего завершения или остановки.

## Настройки движения

В `robot_config.json` указаны параметры текущей сборки. Для своих значений используйте `robot_config.local.json` и передавайте его через `--config`.

| Параметр | Значение | Назначение |
| --- | --- | --- |
| `safe_distance_cm` | `20` | Расстояние остановки перед препятствием |
| `resume_distance_cm` | `30` | Глубина свободного прохода для возврата к исходному направлению |
| `clearance_margin_cm` | `5` | Запас пространства вокруг корпуса |
| `robot_length_cm` / `robot_width_cm` | `24` / `18.5` | Габариты корпуса, см |
| `sensor_forward_offset_cm` | `11` | Смещение излучателя вперёд относительно центра корпуса, см |
| `move_speed` / `turn_speed` | `25` / `10` | PWM прямого движения и поворота |
| `left_drive_trim_pwm` / `right_drive_trim_pwm` | `0` / `0` | Раздельные поправки PWM для прямого движения |
| `turn_right_deg_per_sec` / `turn_left_deg_per_sec` | `60` / `60` | Расчётная скорость поворота корпуса |
| `servo_min_deg` / `servo_max_deg` | `45` / `135` | Границы поворота дальномера |
| `max_escape_angle_deg` | `90` | Максимальное отклонение корпуса при боковом объезде |
| `max_bypass_steps` | `30` | Предел шагов объезда |

Ультразвуковые измерения в неподвижном положении объединяются медианой: нужны минимум три достоверные пробы из пяти. Во время прямого движения используется каждый свежий замер. Недостоверное расстояние останавливает движение; отсутствие измерения не считается свободным путём.

Угол корпуса оценивается по длительности команды. Покрытие, проскальзывание и питание влияют на фактический поворот. Возврат означает восстановление расчётного направления, а не прежней линии пути. Пространство сзади не измеряется; задний ход и поиск сложного маршрута не реализованы.

## Распиновка и ИК-входы

Используется нумерация **GPIO BCM**. Она отличается от физических номеров контактов разъёма.

| Назначение | GPIO BCM |
| --- | --- |
| IN1 / IN2 / IN3 / IN4 | 20 / 21 / 19 / 26 |
| ENA / ENB | 16 / 13 |
| Ультразвук: Echo / Trig | 0 / 1 |
| Сервопривод дальномера | 23 |
| Левый / правый ИК-вход | 12 / 17 |
| RGB: красный / зелёный / синий | 22 / 27 / 24 |
| Кнопка | 8 |

Распиновка соответствует текущей программе. Кнопка пока не управляет запуском. Углы дальномера: 45° — вправо, 90° — вперёд, 135° — влево.

Чтение выбранных ИК-входов:

```bash
sudo python3 robot_navigation.py --mode ir --ir-pins 12,17 --max-seconds 30
```

`levels` содержит сырые уровни 0/1, `transitions` — число смен уровня. Для защиты движения используется флаг `--use-ir` и параметр `ir_active_level`. Защита по умолчанию выключена: размещение и полярность датчиков зависят от сборки. Датчики, направленные на пол, не дают достоверного признака бокового препятствия.

## Журналы

Каждый запуск создаёт папку `logs/ГГГГММДД-ЧЧММСС-микросекунды/` рядом с программой:

- `events.jsonl` — события в формате JSON, по одному на строку;
- `session.log` — текстовый журнал;
- `config.json` — параметры движения данного запуска;
- `color_config.json` — параметры распознавания, только в режиме `color`.

В `session_start` сохраняются аргументы, версия Python и SHA-256 файлов программы. События дальномера содержат исходные пробы и результат фильтрации; команды моторам — мощности и длительности; решения навигации — этап и причину действия или остановки.

В режиме цвета `color_result` записывается при смене результата и раз в пять секунд. Событие содержит доли цветов, причину, координаты рамки и время обработки. `camera_stats` раз в пять секунд показывает частоту захвата и число обработанных кадров. Покадровой записи в журнал нет.

Папка журналов и локальная конфигурация исключены из Git.
